# ADR 002: B-Tree Hypernym Induction for Saturated Hubs

**Status:** Accepted\
**Date:** 2026-10-05\
**Governing Canon:** [`FOUNDATIONAL.md §5.4`](../../FOUNDATIONAL.md), [`docs/ontological-roots.md §3`](../ontological-roots.md)

---

### Context & Problem Statement

As graphs scale, hub nodes accumulate high out-degrees ($> K_{\max} = 10$). Without hierarchical stratification:
1. Uniform Personalized PageRank (PPR) leaks mass across $100+$ neighbors, diluting transition conductance to irrelevant concepts.
2. Retrieved Bridging Subgraphs suffer from hub pollution.
3. Ontological topology collapses into a flat star graph.

### Decision

Adopt the **Deterministic B-Tree Cluster Split & Hypernym Deepening Protocol**:
1. **Trigger Condition:** Saturated hub detection when direct child degree $> K_{\max}$ (default 10).
2. **Deterministic Geometric Partitioning:** Execute SciPy Agglomerative Hierarchical Clustering (HAC) with Ward's minimum-variance linkage (`method='ward'`) over candidate node embeddings. Ward's method is 100% deterministic given a fixed distance matrix (zero random seeds, zero Louvain/K-Means cluster boundary thrashing).
3. **Hypernym Induction via `@llm_tasks("spacy.Raw.v1")` (`temperature=0.1`):**
   - Configured as an official `spacy-llm` task using `spacy.Raw.v1` with a dedicated Jinja2 prompt template (`HYPERNYM_INFERENCE_TEMPLATE` in `src/yaw/nlp/templates.py`).
   - Fed with the complete subnode population: parent domain name & definition, plus each member concept's `name` and full indexing-time `definition`.
   - Prompt: instructs Qwen at `temperature=0.1` to induce a concise 1–3 word noun phrase superclass and 1-sentence gloss in structured JSON: `{"hypernym_name": "...", "definition": "..."}`.
   - Robust Parsing: strips markdown code fences and whitespace before schema validation.
   - Namespace & URI: strictly inherits parent namespace $\to$ `concepts:fault-tolerance-patterns`.
   - Collision Prevention: validated against SQLite `unified_nodes` via EDC `canonicalize.resolve()`.
4. **Taxonomic Subsumption Predicates:**
   - Member $\to$ Hypernym: `subClassOf` (e.g. `circuit-breaker --[subClassOf]--> fault-tolerance-patterns`).
   - Hypernym $\to$ Parent Hub: `subClassOf` (e.g. `fault-tolerance-patterns --[subClassOf]--> resilience`).
   - Downward transition: bidirectional reciprocal edge `hasSubClass` (or inverted transition in SciPy matrix).
5. **Graph Conductance Asymmetry:**
   - Downward (`Hypernym` $\to$ `Member`): conductance $= 1.0$ (low-friction broadcast to concrete particulars).
   - Upward (`Member` $\to$ `Hypernym`): conductance $= 0.2$ (high-friction damping; prevents hub topic leakage).
6. **Execution Lifecycle:** Runs asynchronously during `compile_wiki()` re-consolidation; ingestion uses Inertial Attachment ($\Delta \ge 0.15$ buffer) to avoid real-time re-clustering.

### Consequences & Trade-offs

- **Positive:** Eliminates ontological collapse and hub node mass dilution in SciPy PPR.
- **Positive:** Topology is governed 100% deterministically by geometry; LLMs only label the split groups.
- **Positive:** Asymmetric conductance ensures localized PPR mass focuses on relevant sub-branches without escaping to generic high-level nodes.
- **Requirement:** Node embeddings must be available and populated to compute Ward's minimum-variance distance matrix.
