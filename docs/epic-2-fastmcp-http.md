## Containment and transport contract

- `yaw/mcp_server.py` imports only `yaw.runtime`, `yaw.core.*`, and public transport-library/stdlib APIs (`fastmcp`, `pydantic`, `starlette`, `uvicorn`). Zero direct `pipeline`, `retrieval`, or `qa` imports, and zero private cross-module access (`build_recall_payload`, `format_recall_text`, and `dump_recall_json` enter cleanly via `yaw.runtime`).
- Default endpoint: `http://127.0.0.1:13306/mcp` (`YawConfig.http_host`/`http_port`/`http_path`). Non-loopback `http_host` binds raise `YawRuntimeError("INVALID_INPUT", ...)`.
- `_LoopbackGuardMiddleware` validates `Host` (exactly 1 recognized loopback authority: `localhost`, `127.0.0.1`, or loopback IPv6 `[::1]`) and `Origin` (absent or 1 well-formed HTTP(S) loopback origin) before dispatch across `/mcp`, `/healthz`, `/readyz`, `/status`, and `/_internal/stop`, returning HTTP `403` on rejection.
- `/healthz` returns `200` `{"status": "ok"}`. `/readyz` accepts optional `?wait=` finite non-negative float (`400` on invalid/`NaN`/`<0`), awaits `ready_evt.wait()`, and returns `200` `{"status": "ready"}` only when `snapshot_status(rt).lifecycle == "ready"` and `provider_ready` is true (else `503`). `/status` returns redacted `DaemonStatus`. `POST /_internal/stop` requires matching `X-Yaw-Control-Token` (`403` on missing/mismatch) and sets `server.should_exit = True`.

The canonical sparse slip (`build_recall_payload`, `format_recall_text`, and `dump_recall_json` in `L1` `yaw/retrieval/slip.py`, re-exported via `L4` `yaw/runtime.py`) emits `{"results": [...]}` plus optional top-level keys omitted when empty/false/non-finite: `log_bf: float`, `coverage: float` *(omitted when `results == []`)*, `next: [{"chunk_id": int, "score": float, "label": str}, ...]` *(up to 3 tail candidates with in-RAM sanitized `[:64]` labels and `0` disk opens)*, `links: [{"kind": "cite", "src": int, "dst": int} | {"kind": "pmi", "src": int, "dst": int, "term": str}, ...]` *(at most 1 global rarest cross-doc PMI edge)*, and `card_queued: True`. Each `results[i]` holds `{"rank": int, "chunk_id": int, "score": float, "text": str, "content_hash": str, "source": {"rel_posix_path": str, "start_line": int, "end_line": int}}` where `start_line`/`end_line` emit `hp.resolved_start_line`/`hp.resolved_end_line` (expanded `(es, ee)` AST-island lines on `include_island=True` or exact `(sl, el)` on `read_chunk`), with walk-up AST `"title": str` included iff non-empty and `"stale": True` included iff `stale_on_disk` (omitting false/empty keys; `content_hash` is `"sha256:"` + SHA-256 of the returned UTF-8 text, distinct from `fingerprint_str` `ChunkPointer.source_hash` stored in `chunks`). `dump_recall_json(payload)` enforces `json.dumps(..., allow_nan=False)` (raising `ValueError` on leaked non-finite floats across MCP `recall` and `yaw recall --json`). `format_recall_text(payload)` renders `No matching passages found.` when empty, or optional `certainty: log_bf=... coverage=...`, `[chunk_id=<int>] (path:es-ee) score=...:` blocks (`[STALE ON DISK] <rel_posix_path>` body on drift), optional `next: <id> "<label>" (<score>), ...`, and optional `links: <src>-><dst>, <src>~pmi("<term>")~<dst>` with bare integer IDs.

## Execution and error contracts

- Async MCP tools (`recall`, `expand_neighbors`, `read_chunk`, `write_wiki`) await `yaw.runtime` coroutines directly on the ASGI event loop (`0` custom `ThreadPoolExecutor` pools) so `/healthz`, `/readyz`, `/status`, and `yaw://status` remain responsive (`< 2.0s`) while `/embeddings` blocks; CLI `yaw qa` (`runtime.aask` / `ask`) fails fast with `MODEL_ERROR` when `qa_model = ""` (`lm = None`).
- `YawRuntimeError` maps to redacted `ToolError(f"[{exc.code}] {msg}")` on tools and `ResourceError(f"[{exc.code}] {msg}")` on resources over the 8 live error codes (`INVALID_INPUT`, `SHUTTING_DOWN`, `NOT_READY`, `BUSY`, `EMPTY_INDEX`, `MODEL_ERROR`, `CONSISTENCY_ERROR`; `INDEX_NOT_READY` on missing/stale artifacts).
- Validation ordering: inputs (`INVALID_INPUT`) -> lifecycle (`SHUTTING_DOWN` / `NOT_READY`) -> operation state (`BUSY`, `EMPTY_INDEX`, `CONSISTENCY_ERROR`, `MODEL_ERROR`). `recall` returns `ToolResult` with `results: []` (`"No matching passages found."`) on an empty ready index; `expand_neighbors` and `read_chunk` raise `INVALID_INPUT` for unknown chunk IDs; CLI `yaw qa` raises `EMPTY_INDEX`.
