###### Abstract

Link prediction is a very fundamental task on graphs. Inspired by traditional path-based methods, in this paper we propose a general and flexible representation learning framework based on paths for link prediction. Specifically, we define the representation of a pair of nodes as the *generalized sum* of all path representations, with each path representation as the *generalized product* of the edge representations in the path.
Motivated by the Bellman-Ford algorithm for solving the shortest path problem, we show that the proposed path formulation can be efficiently solved by the generalized Bellman-Ford algorithm. To further improve the capacity of the path formulation, we propose the Neural Bellman-Ford Network (NBFNet), a general graph neural network framework that solves the path formulation with learned operators in the generalized Bellman-Ford algorithm. The NBFNet parameterizes the generalized Bellman-Ford algorithm with 3 neural components, namely Indicator, Message and Aggregate functions, which corresponds to the boundary condition, *multiplication* operator, and *summation* operator respectively11 1 Unless stated otherwise, we use *summation* and *multiplication* to refer the generalized operators in the path formulation, rather than the basic operations of arithmetic.. The NBFNet is very general, covers many traditional path-based methods, and can be applied to both homogeneous graphs and multi-relational graphs (e.g., knowledge graphs) in both transductive and inductive settings. Experiments on both homogeneous graphs and knowledge graphs show that the proposed NBFNet outperforms existing methods by a large margin in both transductive and inductive settings, achieving new state-of-the-art results.

## 1 Introduction

Predicting the interactions between nodes (a.k.a. link prediction) is a fundamental task in the field of graph machine learning. Given the ubiquitous existence of graphs, such a task has many applications, such as recommender system [[29](https://arxiv.org/html/2106.06935v1#bib.bib29)], knowledge graph completion [[36](https://arxiv.org/html/2106.06935v1#bib.bib36)] and drug repurposing [[22](https://arxiv.org/html/2106.06935v1#bib.bib22)].

Traditional methods of link prediction usually define different heuristic metrics over the paths between a pair of nodes. For example, Katz index [[25](https://arxiv.org/html/2106.06935v1#bib.bib25)] is defined as a weighted count of paths between two nodes. Personalized PageRank [[37](https://arxiv.org/html/2106.06935v1#bib.bib37)] measures the similarity of two nodes as the random walk probability from one to the other. Graph distance [[32](https://arxiv.org/html/2106.06935v1#bib.bib32)] uses the length of the shortest path between two nodes to predict their association. These methods have been shown effective on different types of graphs, scaling up to large graphs, and enjoying good interpretability. However, they are designed based on handcrafted metrics and may not be optimal for link prediction on real-world graphs.

To address these limitations, there are some recent advancements based on graph neural networks (GNNs) [[67](https://arxiv.org/html/2106.06935v1#bib.bib67), [50](https://arxiv.org/html/2106.06935v1#bib.bib50)], which automatically extract important features from local subgraphs for link prediction. Thanks to the high expressiveness of GNNs, these methods have shown state-of-the-art performance, and the learned models can generalize to new graphs, i.e., in the inductive setting. However, both scalability and intepretability of these methods is usually compromised. Therefore, we wonder if there exists an approach which has the advantages of both traditional path-based methods and recent approaches based on graph neural networks, i.e., scalability, high model capacity, strong generalization in both transductive and inductive settings, and interpretability.

In this paper, we propose such a solution. Inspired by traditional path-based methods, our goal is to develop a general and flexible representation learning framework for link prediction based on the paths between two nodes. Specifically, we define the representation of a pair of nodes as the *generalized sum* of all the path representations between them, where each path representation is defined as the *generalized product* of the edge representations in the path. Many link prediction methods, such as Katz index [[25](https://arxiv.org/html/2106.06935v1#bib.bib25)], personalized PageRank [[37](https://arxiv.org/html/2106.06935v1#bib.bib37)], graph distance [[32](https://arxiv.org/html/2106.06935v1#bib.bib32)], as well as graph theory algorithms like widest path [[3](https://arxiv.org/html/2106.06935v1#bib.bib3)] and most reliable path [[3](https://arxiv.org/html/2106.06935v1#bib.bib3)], are special instances of this path formulation with different *summation* and *multiplication* operators. Motivated by the polynomial-time algorithm for the shortest path problem [[4](https://arxiv.org/html/2106.06935v1#bib.bib4)], we show that such a formulation can be solved via the generalized Bellman-Ford algorithm [[46](https://arxiv.org/html/2106.06935v1#bib.bib46)] under mild conditions and scale up to large graphs.

The operators in the generalized Bellman-Ford algorithm—*summation* and *multiplication*—are handcrafted and have limited flexibility. Therefore, we further propose the Neural Bellman-Ford Networks (NBFNet), a graph neural network framework that solves the above path formulation with learned operators in the generalized Bellman-Ford algorithm. Specifically, NBFNet parameterizes the generalized Bellman-Ford algorithm with 3 neural components, namely Indicator, Message and Aggregate functions. The Indicator function initializes a representation on each node, which is taken as the boundary condition of the generalized Bellman-Ford algorithm. The Message and the Aggregate functions learn the *multiplication* and *summation* operators respectively.

We show that the Message function can be defined according to the relational operators in knowledge graph embedding methods [[5](https://arxiv.org/html/2106.06935v1#bib.bib5), [62](https://arxiv.org/html/2106.06935v1#bib.bib62), [53](https://arxiv.org/html/2106.06935v1#bib.bib53), [26](https://arxiv.org/html/2106.06935v1#bib.bib26), [47](https://arxiv.org/html/2106.06935v1#bib.bib47)], e.g., as a translation in Euclidean space induced by the relational operators of TransE [[5](https://arxiv.org/html/2106.06935v1#bib.bib5)]. The Aggregate function can be defined as learnable set aggregation functions [[65](https://arxiv.org/html/2106.06935v1#bib.bib65), [60](https://arxiv.org/html/2106.06935v1#bib.bib60), [7](https://arxiv.org/html/2106.06935v1#bib.bib7)]. The whole framework can be efficiently optimized through back-propagation. With other instantiations of Message and Aggregate functions, our framework can also cover some existing works on learning logic rules [[63](https://arxiv.org/html/2106.06935v1#bib.bib63), [41](https://arxiv.org/html/2106.06935v1#bib.bib41)] for link prediction on knowledge graphs. A comparison of operators in our NBFNet and other existing works is listed in Table [1](https://arxiv.org/html/2106.06935v1#S1.T1 "Table 1 ‣ 1 Introduction ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction").

Our NBFNet framework is very general, which can be applied to not only single-relational graphs (e.g., homogeneous graphs) but also multi-relational graphs (e.g., knowledge graphs). We empirically evaluate the proposed NBFNet for link prediction on homogeneous graphs and knowledge graphs in both transductive and inductive settings. Experiments show that the proposed NBFNet outperforms existing state-of-the-art methods by a large margin in all settings, with an average relative performance gain of 14% on knowledge graph completion (HITS@1) in transductive setting and 16% on inductive relation prediction (HITS@10). We also show that the proposed NBFNet is indeed interpretable by visualizing the top-k relevant paths for link prediction on knowledge graphs.

## 2 Related Work

Existing work on link prediction can be generally classified into 3 main paradigms: path-based methods, embedding methods, and graph neural networks.

Path-based Methods. Path-based methods have a long history in the literature of link prediction.
Early methods on homogeneous graphs compute the similarity between two nodes based on the weighted count of paths (Katz index [[25](https://arxiv.org/html/2106.06935v1#bib.bib25)]), random walk probability (personalized PageRank [[37](https://arxiv.org/html/2106.06935v1#bib.bib37)]) or the length of the shortest path (graph distance [[32](https://arxiv.org/html/2106.06935v1#bib.bib32)]). SimRank [[23](https://arxiv.org/html/2106.06935v1#bib.bib23)] uses advanced metrics such as the expected meeting distance on homogeneous graphs, which is extended by PathSim [[46](https://arxiv.org/html/2106.06935v1#bib.bib46)] to heterogeneous graphs. On knowledge graphs, Path Ranking [[30](https://arxiv.org/html/2106.06935v1#bib.bib30), [13](https://arxiv.org/html/2106.06935v1#bib.bib13)] directly uses relational paths as symbolic features for prediction. Rule mining methods, such as NeuralLP [[63](https://arxiv.org/html/2106.06935v1#bib.bib63)] and DRUM [[41](https://arxiv.org/html/2106.06935v1#bib.bib41)], learn probabilistic logical rules to weight different paths. Path representation methods, such as Path-RNN [[35](https://arxiv.org/html/2106.06935v1#bib.bib35)] and its successors [[9](https://arxiv.org/html/2106.06935v1#bib.bib9), [56](https://arxiv.org/html/2106.06935v1#bib.bib56)], encode each path with recurrent neural networks (RNNs), and aggregate paths for prediction. However, these methods need to traverse an exponential number of paths and are limited to very short paths, e.g., $\leq 3$ edges. Another stream of works [[59](https://arxiv.org/html/2106.06935v1#bib.bib59), [8](https://arxiv.org/html/2106.06935v1#bib.bib8), [20](https://arxiv.org/html/2106.06935v1#bib.bib20)] learns an agent to collect useful paths for link prediction. While these methods can produce explainable paths, they suffer from extremely sparse rewards and require careful engineering of the reward function [[33](https://arxiv.org/html/2106.06935v1#bib.bib33)] or the search strategy [[45](https://arxiv.org/html/2106.06935v1#bib.bib45)]. Some other works [[6](https://arxiv.org/html/2106.06935v1#bib.bib6), [39](https://arxiv.org/html/2106.06935v1#bib.bib39)] adopt variational inference to learn a path finder and a path reasoner for link prediction. The most relevant work to this paper is All-Paths [[52](https://arxiv.org/html/2106.06935v1#bib.bib52)], which computes all paths between two nodes with dynamic programming. However, All-Paths can only be applied with the bilinear model, while our NBFNet is general and enjoys a rich design space from existing knowledge graph embedding methods and set aggregation functions.

Embedding Methods. Embedding methods learn a distributed representation for each node and edge by preserving the edge structure of the graph. Representative methods include DeepWalk [[38](https://arxiv.org/html/2106.06935v1#bib.bib38)] and LINE [[48](https://arxiv.org/html/2106.06935v1#bib.bib48)] on homogeneous graphs, and TransE [[5](https://arxiv.org/html/2106.06935v1#bib.bib5)], DistMult [[62](https://arxiv.org/html/2106.06935v1#bib.bib62)] and RotatE [[47](https://arxiv.org/html/2106.06935v1#bib.bib47)] on knowledge graphs. Later works improve embedding methods with new score functions [[53](https://arxiv.org/html/2106.06935v1#bib.bib53), [11](https://arxiv.org/html/2106.06935v1#bib.bib11), [26](https://arxiv.org/html/2106.06935v1#bib.bib26), [47](https://arxiv.org/html/2106.06935v1#bib.bib47), [49](https://arxiv.org/html/2106.06935v1#bib.bib49)] that capture common semantic patterns of the relations, or search the score function in a general design space [[69](https://arxiv.org/html/2106.06935v1#bib.bib69)]. Embedding methods achieve promising results on link prediction, and can be scaled to very large graphs using multiple GPUs [[71](https://arxiv.org/html/2106.06935v1#bib.bib71)]. However, embedding methods do not explicitly encode local subgraphs between node pairs and cannot be applied to the inductive setting.

Graph Neural Networks. Graph neural networks (GNNs) [[42](https://arxiv.org/html/2106.06935v1#bib.bib42)] are a family of representation learning models that encode topological structures of graphs. Many works [[27](https://arxiv.org/html/2106.06935v1#bib.bib27), [54](https://arxiv.org/html/2106.06935v1#bib.bib54), [60](https://arxiv.org/html/2106.06935v1#bib.bib60), [58](https://arxiv.org/html/2106.06935v1#bib.bib58)] have been developed to learn better representations for nodes or graphs. For link prediction, the prevalent frameworks [[28](https://arxiv.org/html/2106.06935v1#bib.bib28), [43](https://arxiv.org/html/2106.06935v1#bib.bib43), [10](https://arxiv.org/html/2106.06935v1#bib.bib10)] adopt an auto-encoder formulation, which uses GNNs to encode node representations, and decodes edges as a function over node pairs. However, such frameworks do not capture the local subgraphs between nodes, and can be only applied to the transductive setting. Another stream of frameworks, such as SEAL [[67](https://arxiv.org/html/2106.06935v1#bib.bib67)] and GraIL [[50](https://arxiv.org/html/2106.06935v1#bib.bib50)], explicitly encodes the subgraph around each node pair for link prediction. While these frameworks are proved to be more powerful than the auto-encoder formulation [[68](https://arxiv.org/html/2106.06935v1#bib.bib68)] and can solve the inductive setting, they require to materialize a subgraph for each link, which is not scalable to large graphs. By contrast, our NBFNet explicitly captures the paths between two nodes for link prediction, meanwhile achieves a relatively low time complexity (Appendix [C](https://arxiv.org/html/2106.06935v1#A3 "Appendix C Comparison of GNN Frameworks ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction")). There are also some works trying to scale GNNs for link prediction by dynamically pruning the set of nodes in message passing [[61](https://arxiv.org/html/2106.06935v1#bib.bib61), [18](https://arxiv.org/html/2106.06935v1#bib.bib18)]. These methods are complementary to our NBFNet, and may be incorporated into our method to get further acceleration.

## 3 Methodology

In this section, we first define a path formulation for link prediction. Our path formulation generalizes several traditional methods, and can be efficiently solved by the generalized Bellman-Ford algorithm. Then we propose Neural Bellman-Ford Networks to learn the path formulation with neural functions.

### 3.1 Path Formulation for Link Prediction

We consider the link prediction problem on both knowledge graphs and homogeneous graphs. A knowledge graph is denoted by ${\mathcal{G}}=({\mathcal{V}},{\mathcal{E}},{\mathcal{R}})$, where ${\mathcal{V}}$ and ${\mathcal{E}}$ represent the set of entities (nodes) and relations (edges) respectively, and ${\mathcal{R}}$ is the set of relation types. We use the notation ${\mathcal{N}}(u)$ to denote the set of nodes connected to $u$, and ${\mathcal{E}}(u)$ to denote the set of edges ending with node $u$. A homogeneous graph ${\mathcal{G}}=({\mathcal{V}},{\mathcal{E}})$ can be viewed as a special case of knowledge graphs, with only one relation type for all edges. Throughout this paper, we use bold terms, ${\bm{w}}_{q}(e)$ or ${\bm{h}}_{q}(u,v)$, to denote vector representations, and italic terms, $w_{e}$ or $w_{uv}$, to denote scalars like the edge weight of $e=(u,v)$. Without loss of generality, we derive our method based on knowledge graphs, while our method can also be applied to homogeneous graphs.

Path Formulation. Link prediction is aimed at predicting the existence of a query relation $q$ between a head entity $u$ and a tail entity $v$. From a representation learning perspective, this requires to learn a pairwise representation ${\bm{h}}_{q}(u,v)$, which captures the local subgraph structure between $u$ and $v$ w.r.t. the query relation $q$. In traditional methods [[30](https://arxiv.org/html/2106.06935v1#bib.bib30)], such a local structure is encoded by counting different types of random walks from $u$ to $v$. Inspired by this construction, we formulate the pairwise representation as a *generalized sum* of path representations between $u$ and $v$ with a commutative *summation* operator $\oplus$. Each path representation ${\bm{h}}_{q}(P)$ is defined as a *generalized product* of the edge representations in the path with the *multiplication* operator $\otimes$.

|  |  | $\displaystyle{\bm{h}}_{q}(u,v)={\bm{h}}_{q}(P_{1})\oplus{\bm{h}}_{q}(P_{2})\oplus...\oplus{\bm{h}}_{q}(P_{&#124;{\mathcal{P}}_{uv}&#124;})&#124;_{P_{i}\in{\mathcal{P}}_{uv}}\triangleq\bigoplus_{P\in{\mathcal{P}}_{uv}}{\bm{h}}_{q}(P)$ |  | (1) |
| --- | --- | ------------------------------ | --- | --- |
|  |  | $\displaystyle{\bm{h}}_{q}(P=(e_{1},e_{2},...,e_{&#124;P&#124;}))={\bm{w}}_{q}(e_{1})\otimes{\bm{w}}_{q}(e_{2})\otimes...\otimes{\bm{w}}_{q}(e_{&#124;P&#124;})\triangleq\bigotimes_{i=1}^{&#124;P&#124;}{\bm{w}}_{q}(e_{i})$ |  | (2) |

where ${\mathcal{P}}_{uv}$ denotes the set of paths from $u$ to $v$ and ${\bm{w}}_{q}(e_{i})$ is the representation of edge $e_{i}$. Note the *multiplication* operator $\otimes$ is not required to be commutative (e.g., matrix multiplication), therefore we define $\bigotimes$ to compute the product following the exact order. Intuitively, the path formulation can be interpreted as a depth-first-search (DFS) algorithm, where one searches all possible paths from $u$ to $v$, computes their representations (Equation [2](https://arxiv.org/html/2106.06935v1#S3.E2 "In 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction")) and aggregates the results (Equation [1](https://arxiv.org/html/2106.06935v1#S3.E1 "In 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction")). Such a formulation is capable of modeling several traditional link prediction methods, as well as graph theory algorithms. Formally, Theorem [1](https://arxiv.org/html/2106.06935v1#Thmthm1 "Theorem 1 ‣ 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction")-[5](https://arxiv.org/html/2106.06935v1#Thmthm5 "Theorem 5 ‣ 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") state the corresponding path formulations for 3 link prediction methods and 2 graph theory algorithms respectively. See Appendix [A](https://arxiv.org/html/2106.06935v1#A1 "Appendix A Path Formulations for Traditional Methods ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") for proofs.

###### Theorem 1

Katz index is a path formulation with $\oplus=+$, $\otimes=\times$ and ${\bm{w}}_{q}(e)=\beta w_{e}$.

###### Theorem 2

Personalized PageRank is a path formulation with $\oplus=+$, $\otimes=\times$ and ${\bm{w}}_{q}(e)=\alpha w_{uv}/\sum\nolimits_{v^{\prime}\in{\mathcal{N}}(u)}w_{uv^{\prime}}$.

###### Theorem 3

Graph distance is a path formulation with $\oplus=\min$, $\otimes=+$ and ${\bm{w}}_{q}(e)=w_{e}$.

###### Theorem 4

Widest path is a path formulation with $\oplus=\max$, $\otimes=\min$ and ${\bm{w}}_{q}(e)=w_{e}$.

###### Theorem 5

Most reliable path is a path formulation with $\oplus=\max$, $\otimes=\times$ and ${\bm{w}}_{q}(e)=w_{e}$.

Generalized Bellman-Ford Algorithm. While the above formulation captures important heuristics for link prediction, it is computationally expensive since the number of paths grows exponentially with the path length.
Previous works [[35](https://arxiv.org/html/2106.06935v1#bib.bib35), [9](https://arxiv.org/html/2106.06935v1#bib.bib9), [56](https://arxiv.org/html/2106.06935v1#bib.bib56)] that directly computes the exponential number of paths can only afford a maximal path length of 3.
A more scalable solution is to use the generalized Bellman-Ford algorithm [[3](https://arxiv.org/html/2106.06935v1#bib.bib3)]. Specifically, assuming the operators $\langle\oplus,\otimes\rangle$ satisfy a semiring system [[19](https://arxiv.org/html/2106.06935v1#bib.bib19)] with *summation identity* $\textcircled{\scriptsize{0}}_{q}$ and *multiplication identity* $\textcircled{\scriptsize{1}}_{q}$, we have the following algorithm.

|  | $\displaystyle{\bm{h}}_{q}^{(0)}(u,v)$ | $\displaystyle\leftarrow\text{1}_{q}(u=v)$ |  | (3) |
| --- | ------------------------------ | ------------------------------ | --- | --- |
|  | $\displaystyle{\bm{h}}_{q}^{(t)}(u,v)$ | $\displaystyle\leftarrow\left(\bigoplus_{(x,r,v)\in{\mathcal{E}}(v)}{\bm{h}}_{q}^{(t-1)}(u,x)\otimes{\bm{w}}_{q}(x,r,v)\right)\oplus{\bm{h}}_{q}^{(0)}(u,v)$ |  | (4) |

where $\text{1}_{q}(u=v)$ is the indicator function that outputs $\textcircled{\scriptsize{1}}_{q}$ if $u=v$ and $\textcircled{\scriptsize{0}}_{q}$ otherwise. ${\bm{w}}_{q}(x,r,v)$ is the representation for edge $e=(x,r,v)$ and $r$ is the relation type of the edge. Equation [3](https://arxiv.org/html/2106.06935v1#S3.E3 "In 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") is known as the boundary condition, while Equation [4](https://arxiv.org/html/2106.06935v1#S3.E4 "In 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") is known as the Bellman-Ford iteration. The high-level idea of the generalized Bellman-Ford algorithm is to compute the pairwise representation ${\bm{h}}_{q}(u,v)$ for all $v\in{\mathcal{V}}$ in parallel, and reduce the total computation by the distributive property of *multiplication* over *summation*. When $\oplus=min$ and $\otimes=+$, it recovers the original Bellman-Ford algorithm for the shortest path problem [[4](https://arxiv.org/html/2106.06935v1#bib.bib4)]. See Appendix [B](https://arxiv.org/html/2106.06935v1#A2 "Appendix B Generalized Bellman-Ford Algorithm ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") for preliminaries and the proof of the above algorithm.

###### Theorem 6

Katz index, personalized PageRank, graph distance, widest path and most reliable path can be solved via the generalized Bellman-Ford algorithm.

### 3.2 Neural Bellman-Ford Networks

While the generalized Bellman-Ford algorithm can solve many classical methods (Theorem [6](https://arxiv.org/html/2106.06935v1#Thmthm6 "Theorem 6 ‣ 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction")), these methods instantiate the path formulation with handcrafted operators (Table [1](https://arxiv.org/html/2106.06935v1#S1.T1 "Table 1 ‣ 1 Introduction ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction")), and may not be optimal for link prediction. To improve the capacity of path formulation, we propose a general framework, Neural Bellman-Ford Networks (NBFNet), to learn the operators in the pairwise representations.

Neural Parameterization. We relax the semiring assumption and parameterize the generalized Bellman-Ford algorithm (Equation [3](https://arxiv.org/html/2106.06935v1#S3.E3 "In 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") and [4](https://arxiv.org/html/2106.06935v1#S3.E4 "In 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction")) with 3 neural functions, namely Indicator, Message and Aggregate functions. The Indicator function replaces the *indicator* function $\text{1}_{q}(u=v)$. The Message function replaces the binary *multiplication* operator $\otimes$. The Aggregate function is a permutation invariant function over sets that replaces the n-ary *summation* operator $\bigoplus$. Note that one may alternatively define Aggregate as the commutative binary operator $\oplus$ and apply it to a sequence of messages. However, this will make the parameterization more complicated.

Now consider the generalized Bellman-Ford algorithm for a given entity $u$ and relation $q$. In this context, we abbreviate ${\bm{h}}_{q}^{(t)}(u,v)$ as ${\bm{h}}^{(t)}_{v}$, i.e., a representation on entity $v$ in the $t$-th iteration. It should be stressed that ${\bm{h}}^{(t)}_{v}$ is still a pairwise representation, rather than a node representation. By substituting the neural functions into Equation [3](https://arxiv.org/html/2106.06935v1#S3.E3 "In 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") and [4](https://arxiv.org/html/2106.06935v1#S3.E4 "In 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction"), we get our Neural Bellman-Ford Networks.

|  | $\displaystyle{\bm{h}}^{(0)}_{v}$ | $\displaystyle\leftarrow\textsc{Indicator}(u,v,q)$ |  | (5) |
| --- | ------------------------------ | ------------------------------ | --- | --- |
|  | $\displaystyle{\bm{h}}^{(t)}_{v}$ | $\displaystyle\leftarrow\textsc{Aggregate}\left(\left\{\textsc{Message}\left({\bm{h}}^{(t-1)}_{x},{\bm{w}}_{q}(x,r,v)\right)\middle&#124;(x,r,v)\in{\mathcal{E}}(v)\right\}\cup\left\{{\bm{h}}^{(0)}_{v}\right\}\right)$ |  | (6) |

*Algorithm 1  Neural Bellman-Ford Networks*

Input: source node $u$, query relation $q$, #layers $T$
Output: pair representations ${\bm{h}}_{q}(u,v)$ for all $v\in{\mathcal{V}}$

1: for $v\in{\mathcal{V}}$ do $\triangleright$ Boundary condition

2: ${\bm{h}}_{v}^{(0)}\leftarrow\textsc{Indicator}(u,v,q)$

3: end for

4: for $t\leftarrow 1$ to $T$ do $\triangleright$ Bellman-Ford iteration

5: for $v\in{\mathcal{V}}$ do

6: ${\mathcal{M}}^{(t)}\leftarrow\left\{{\bm{h}}_{v}^{(0)}\right\}$ $\triangleright$ Message augmentation

7: for $(x,r,v)\in{\mathcal{E}}(v)$ do

8: ${\bm{m}}_{(x,r,v)}^{(t)}\leftarrow$ Message(t)(${\bm{h}}_{x}^{(t-1)},{\bm{w}}_{q}(x,r,v)$)

9: ${\mathcal{M}}^{(t)}\leftarrow{\mathcal{M}}^{(t)}\cup\left\{{\bm{m}}_{(x,r,v)}^{(t)}\right\}$

10: end for

11: ${\bm{h}}_{v}^{(t)}\leftarrow$ Aggregate(t)(${\mathcal{M}}^{(t)}$)

12: end for

13: end for

14: return ${\bm{h}}_{v}^{(T)}$ as ${\bm{h}}_{q}(u,v)$ for all $v\in{\mathcal{V}}$

NBFNet can be interpreted as a novel GNN framework for learning pairwise representations. Compared to common GNN frameworks [[28](https://arxiv.org/html/2106.06935v1#bib.bib28), [43](https://arxiv.org/html/2106.06935v1#bib.bib43)] that compute the pairwise representation as two independent node representations ${\bm{h}}_{q}(u)$ and ${\bm{h}}_{q}(v)$, NBFNet initializes a representation on the source node $u$, and readouts the pairwise representation on the target node $v$. Intuitively, our framework can be viewed as a source-specific message passing process, where every node learns a representation conditioned on the source node. The pseudo code of NBFNet is outlined in Algorithm [1](https://arxiv.org/html/2106.06935v1#alg1 "Algorithm 1 ‣ 3.2 Neural Bellman-Ford Networks ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction").

Design Space. Now we discuss some principled designs for Message, Aggregate and Indicator functions by drawing insights from traditional methods. Note the potential design space for NBFNet is way larger than what is presented here, as one can always borrow Message and Aggregate from the arsenal of message-passing GNNs [[17](https://arxiv.org/html/2106.06935v1#bib.bib17), [14](https://arxiv.org/html/2106.06935v1#bib.bib14), [60](https://arxiv.org/html/2106.06935v1#bib.bib60)].

For the Message function, traditional methods instantiate it as natural summation, natural multiplication or min over scalars. Therefore, we may use the vectorized version of summation or multiplication. Intuitively, summation of ${\bm{h}}^{(t-1)}_{x}$ and ${\bm{w}}_{q}(x,r,v)$ can be interpreted as a translation of ${\bm{h}}^{(t-1)}_{x}$ by ${\bm{w}}_{q}(x,r,v)$ in the pairwise representation space, while multiplication corresponds to scaling. Such transformations correspond to the relational operators [[16](https://arxiv.org/html/2106.06935v1#bib.bib16), [40](https://arxiv.org/html/2106.06935v1#bib.bib40)] in knowledge graph embeddings [[5](https://arxiv.org/html/2106.06935v1#bib.bib5), [62](https://arxiv.org/html/2106.06935v1#bib.bib62), [53](https://arxiv.org/html/2106.06935v1#bib.bib53), [26](https://arxiv.org/html/2106.06935v1#bib.bib26), [47](https://arxiv.org/html/2106.06935v1#bib.bib47)]. For example, translation and scaling are the relational operators used in TransE [[5](https://arxiv.org/html/2106.06935v1#bib.bib5)] and DistMult [[62](https://arxiv.org/html/2106.06935v1#bib.bib62)] respectively. We also consider the rotation operator in RotatE [[47](https://arxiv.org/html/2106.06935v1#bib.bib47)].

The Aggregate function is instantiated as natural summation, max or min in traditional methods, which are reminiscent of set aggregation functions [[65](https://arxiv.org/html/2106.06935v1#bib.bib65), [60](https://arxiv.org/html/2106.06935v1#bib.bib60), [7](https://arxiv.org/html/2106.06935v1#bib.bib7)] used in GNNs. Therefore, we specify the Aggregate function to be sum, mean, or max, followed by a linear transformation and a non-linear activation. We also consider the principal neighborhood aggregation (PNA) proposed in a recent work [[7](https://arxiv.org/html/2106.06935v1#bib.bib7)], which jointly learns the types and scales of the aggregation function.

The Indicator function is aimed at providing a non-trivial representation for the source node $u$ as the boundary condition. Therefore, we learn a query embedding ${\bm{q}}$ for $\textcircled{\scriptsize{1}}_{q}$ and define Indicator function as $\text{1}(u=v)*{\bm{q}}$. Note it is also possible to additionally learn an embedding for $\textcircled{\scriptsize{0}}_{q}$. However, we find a single query embedding works better in practice.

The edge representation ${\bm{w}}_{q}(x,r,v)$ is parameterized as a learnable relation embedding ${\bm{r}}^{(t)}$. Similar to NeuralLP [[63](https://arxiv.org/html/2106.06935v1#bib.bib63)] & DRUM [[41](https://arxiv.org/html/2106.06935v1#bib.bib41)], we use different embeddings for different iterations, but share the embeddings across different queries, i.e., ${\bm{r}}^{(t)}$ depends on $t$ but not $q$. Note NBFNet only learns embeddings for relations but not entities, and therefore can solve the inductive setting.

Link Prediction. We now show how to apply the learned pair representations to the link prediction problem. We use the pair representations to predict the conditional likelihood of the tail entity $p(v&#124;u,q)=\sigma(f({\bm{h}}_{q}(u,v)))$, where $\sigma(\cdot)$ is the sigmoid function and $f(\cdot)$ is a feed-forward neural network. Following previous works [[5](https://arxiv.org/html/2106.06935v1#bib.bib5), [47](https://arxiv.org/html/2106.06935v1#bib.bib47)], we minimize the negative log-likelihood of positive and negative triplets (Equation [7](https://arxiv.org/html/2106.06935v1#S3.E7 "In 3.2 Neural Bellman-Ford Networks ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction")). The negative samples are generated according to Partial Completeness Assumption (PCA) [[12](https://arxiv.org/html/2106.06935v1#bib.bib12)], which corrupts one of the entities in a positive triplet to create a negative sample. Since the edges in homogeneous graphs are undirected, we symmetrize the representations and define $p(u,v)=\sigma(f({\bm{h}}(u,v)+{\bm{h}}(v,u)))$. Equation [8](https://arxiv.org/html/2106.06935v1#S3.E8 "In 3.2 Neural Bellman-Ford Networks ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") shows the loss for homogeneous graphs.

Time Complexity. One advantage of NBFNet is that it has a relatively low time complexity during inference22 2 Although the same analysis can be applied to training on a fixed number of samples, we note it is less instructive since one can trade-off samples for performance, and the trade-off varies from method to method.. Consider a scenario where a model is required to infer the conditional likelihood of all possible triplets $p(v&#124;u,q)$. We group triplets with the same condition $u,q$ together, where each group contains $&#124;{\mathcal{V}}&#124;$ triplets. For each group, we only need to execute Algorithm [1](https://arxiv.org/html/2106.06935v1#alg1 "Algorithm 1 ‣ 3.2 Neural Bellman-Ford Networks ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") once to get their predictions. Since a small constant number of iterations $T$ is enough for NBFNet to converge (Table [5(b)](https://arxiv.org/html/2106.06935v1#S4.T5.st2 "In Table 5 ‣ 4.3 Ablation Study ‣ 4 Experiment ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction")), Algorithm [1](https://arxiv.org/html/2106.06935v1#alg1 "Algorithm 1 ‣ 3.2 Neural Bellman-Ford Networks ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") has a time complexity of $O(&#124;{\mathcal{E}}&#124;d+&#124;{\mathcal{V}}&#124;d^{2})$, where $d$ is the dimension of representations. Therefore, the amortized time complexity for a single triplet is $O\left(\frac{&#124;{\mathcal{E}}&#124;d}{&#124;{\mathcal{V}}&#124;}+d^{2}\right)$. For a detailed comparison on the time complexity of GNN frameworks, please refer to Appendix [C](https://arxiv.org/html/2106.06935v1#A3 "Appendix C Comparison of GNN Frameworks ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction").

### 4.1 Experiment Setup

We evaluate NBFNet in three settings, knowledge graph completion, homogeneous graph link prediction and inductive relation prediction. The former two are transductive settings, while the last is an inductive setting.
For knowledge graphs, we use FB15k-237 [[51](https://arxiv.org/html/2106.06935v1#bib.bib51)] and WN18RR [[11](https://arxiv.org/html/2106.06935v1#bib.bib11)].
We use the standard transductive splits [[51](https://arxiv.org/html/2106.06935v1#bib.bib51), [11](https://arxiv.org/html/2106.06935v1#bib.bib11)] and inductive splits [[50](https://arxiv.org/html/2106.06935v1#bib.bib50)] of these datasets.
For homogeneous graphs, we use Cora, Citeseer and PubMed [[44](https://arxiv.org/html/2106.06935v1#bib.bib44)].
Following previous works [[28](https://arxiv.org/html/2106.06935v1#bib.bib28), [10](https://arxiv.org/html/2106.06935v1#bib.bib10)], we split the edges into train/valid/test with a ratio of 85:5:10. Statistics of datasets can be found in Appendix [E](https://arxiv.org/html/2106.06935v1#A5 "Appendix E Statistics of Datasets ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction").

Implementation Details. Our implementation generally follows the open source codebases of knowledge graph completion33 3 <https://github.com/DeepGraphLearning/KnowledgeGraphEmbedding>. MIT license. and homogeneous graph link prediction44 4 <https://github.com/tkipf/gae>. MIT license.. For knowledge graphs, we follow [[63](https://arxiv.org/html/2106.06935v1#bib.bib63), [41](https://arxiv.org/html/2106.06935v1#bib.bib41)] and augment each triplet $\langle$u, q, v$\rangle$ with a flipped triplet $\langle$v, q-1, u$\rangle$. For homogeneous graphs, we follow [[27](https://arxiv.org/html/2106.06935v1#bib.bib27), [28](https://arxiv.org/html/2106.06935v1#bib.bib28)] and augment each node $u$ with a self loop $\langle$u, u$\rangle$. We instantiate NBFNet with 6 layers, each with 32 hidden units. The feed-forward network $f(\cdot)$ is set to a 2-layer MLP with 128 hidden units. ReLU is used as the activation function for all hidden layers. Our model is trained on 4 Tesla V100 GPUs for 20 epochs, with Adam optimizer. See Appendix [F](https://arxiv.org/html/2106.06935v1#A6 "Appendix F Implementation Details ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") for more details.

Evaluation. We follow the filtered ranking protocol [[5](https://arxiv.org/html/2106.06935v1#bib.bib5)] for knowledge graph completion. For a test triplet $\langle$u, q, v$\rangle$, we rank it against all negative triplets $\langle$u, q, v’$\rangle$ or $\langle$u’, q, v$\rangle$ that do not appear in the knowledge graph. We report mean rank (MR), mean reciprocal rank (MRR) and HITS at N (H@N) for knowledge graph completion. For inductive relation prediction, we follow [[50](https://arxiv.org/html/2106.06935v1#bib.bib50)] and draw 50 negative triplets for each positive triplet and use the above filtered ranking. We report HITS@10 for inductive relation prediction. For homogeneous graph link prediction, we follow [[28](https://arxiv.org/html/2106.06935v1#bib.bib28)] and compare the positive edges against the same number of negative edges. We report area under the receiver operating characteristic curve (AUROC) and average precision (AP) for homogeneous graphs.

Baselines. We compare NBFNet against path-based methods, embedding methods, and GNNs. These include 9 baselines for knowledge graph completion, 9 baselines for homogeneous graph link prediction and 4 baselines for inductive relation prediction. Note the inductive setting only includes path-based methods and GNNs, since existing embedding methods cannot handle this setting.

### 4.4 Path Explanations of Predictions

One advantage of NBFNet is that we can explain its predictions through path groundings. Intuitively, the explanations should contain paths that contribute most to the prediction $p(u,q,v)$. Following local explanation methods [[2](https://arxiv.org/html/2106.06935v1#bib.bib2), [66](https://arxiv.org/html/2106.06935v1#bib.bib66)], we assume our NBFNet is locally linear w.r.t. the set of all paths, and define the importance of a path as its weight in the local linear model, i.e., the partial derivative of the prediction w.r.t. the path. Formally, the top-k path explanations for $p(u,q,v)$ are defined as

|  | $P_{1},P_{2},...,P_{k}=\topk_{P\in{\mathcal{P}}_{uv}}\frac{\partial{p(u,q,v)}}{\partial{P}}$ |  | (9) |
| --- | ------------------------------ | --- | --- |

Note this formulation generalizes the definition of logical rules [[63](https://arxiv.org/html/2106.06935v1#bib.bib63), [41](https://arxiv.org/html/2106.06935v1#bib.bib41)] to non-linear models. While directly computing the importance of all paths is intractable, we approximate them with edge importance. Specifically, the importance of each path is approximated by the sum of the importance of edges in that path, where edge importance is obtained via auto differentiation. Then the top-k path explanations are equivalent to the top-k longest paths on the edge importance graph, which can be solved by a Bellman-Ford-style beam search. Better approximation is left as a future work.

## 5 Discussion and Conclusion

Limitations. We observe there are a few limitations for our NBFNet. First, the assumption of the generalized Bellman-Ford algorithm requires the operators $\langle\oplus,\otimes\rangle$ to satisfy a semiring. Due to the non-linear activation functions in neural networks, this assumption does not hold for NBFNet, and we do not have a theoretical guarantee on the loss incurred by this relaxation. Second, NBFNet is only verified on simple edge prediction, while there are other link prediction variants. For instance, one may want to handle logical queries with conjunctions and disjunctions [[16](https://arxiv.org/html/2106.06935v1#bib.bib16), [40](https://arxiv.org/html/2106.06935v1#bib.bib40)], or queries with question-answering contexts [[64](https://arxiv.org/html/2106.06935v1#bib.bib64)]. In the future, we would like to understand how NBFNet approximates the path formulation, as well as apply NBFNet to other link prediction settings.

Social Impacts. Link prediction has a wide range of beneficial applications, including recommender systems, knowledge graph completion and drug repurposing. However, there are also some potentially negative impacts. First, NBFNet may encode the bias present in the data, which leads to stereotyped predictions when the prediction is applied to a user on a social or e-commerce platform. Second, some harmful network activities could be augmented by link prediction models, e.g., spamming, phishing, and social engineering. We expect future studies will mitigate these issues.

Conclusion. We present a representation learning framework based on paths for link prediction. Our path formulation generalizes several traditional methods, and can be efficiently solved via the generalized Bellman-Ford algorithm. To improve the capacity of the path formulation, we propose NBFNet, which parameterizes the generalized Bellman-Ford algorithm with learned Indicator, Message, Aggregate functions. Experiments on knowledge graphs and homogeneous graphs show that NBFNet outperforms a wide range of methods in both transductive and inductive settings.

## Appendix A Path Formulations for Traditional Methods

Here we demonstrate our path formulation is capable of modeling traditional link prediction methods like Katz index [[25](https://arxiv.org/html/2106.06935v1#bib.bib25)], personalized PageRank [[37](https://arxiv.org/html/2106.06935v1#bib.bib37)] and graph distance [[32](https://arxiv.org/html/2106.06935v1#bib.bib32)], as well as graph theory algorithms like widest path [[3](https://arxiv.org/html/2106.06935v1#bib.bib3)] and most reliable path [[3](https://arxiv.org/html/2106.06935v1#bib.bib3)].

Recall the path formulation is defined as

|  |  | $\displaystyle{\bm{h}}_{q}(u,v)={\bm{h}}_{q}(P_{1})\oplus{\bm{h}}_{q}(P_{2})\oplus...\oplus{\bm{h}}_{q}(P_{&#124;{\mathcal{P}}_{uv}&#124;})&#124;_{P_{i}\in{\mathcal{P}}_{uv}}\triangleq\bigoplus_{P\in{\mathcal{P}}_{uv}}{\bm{h}}_{q}(P)$ |  | ([1](https://arxiv.org/html/2106.06935v1#S3.E1 "In 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction")) |
| --- | --- | ------------------------------ | --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|  |  | $\displaystyle{\bm{h}}_{q}(P=(e_{1},e_{2},...,e_{&#124;P&#124;}))={\bm{w}}_{q}(e_{1})\otimes{\bm{w}}_{q}(e_{2})\otimes...\otimes{\bm{w}}_{q}(e_{&#124;P&#124;})\triangleq\bigotimes_{i=1}^{&#124;P&#124;}{\bm{w}}_{q}(e_{i})$ |  | ([2](https://arxiv.org/html/2106.06935v1#S3.E2 "In 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction")) |

which can be written in the following compact form

|  | ${\bm{h}}_{q}(u,v)=\bigoplus_{P\in{\mathcal{P}}_{uv}}\bigotimes_{i=1}^{&#124;P&#124;}{\bm{w}}_{q}(e_{i})$ |  | (10) |
| --- | ------------------------------ | --- | ---- |

### A.1 Katz Index

The Katz index for a pair of nodes $u$, $v$ is defined as a weighted count of paths between $u$ and $v$, penalized by an attenuation factor $\beta\in(0,1)$. Formally, it can be written as

|  | $\text{Katz}(u,v)=\sum_{t=1}^{\infty}\beta^{t}{\bm{e}}_{u}^{\top}{\bm{A}}^{t}{\bm{e}}_{v}$ |  | (11) |
| --- | ------------------------------ | --- | ---- |

where ${\bm{A}}$ denotes the adjacency matrix and ${\bm{e}}_{u}$, ${\bm{e}}_{v}$ denote the one-hot vector for nodes $u$, $v$ respectively. The term ${\bm{e}}_{u}^{\top}{\bm{A}}^{t}{\bm{e}}_{v}$ counts all paths of length $t$ between $u$, and $v$ and shorter paths are assigned with larger weights.

See [1](https://arxiv.org/html/2106.06935v1#Thmthm1 "Theorem 1 ‣ 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") Proof. We show that $\text{Katz}(u,v)$ can be transformed into a summation over all paths between $u$ and $v$, where each path is represented by a product of damped edge weights in the path.
Mathematically, it can be derived as

|  | $\displaystyle\text{Katz}(u,v)$ | $\displaystyle=\sum_{t=1}^{\infty}\beta^{t}\sum_{P\in{\mathcal{P}}_{uv}:&#124;P&#124;=t}\prod_{e\in P}w_{e}$ |  | (12) |
| --- | ------------------------------ | ------------------------------ | --- | ---- |
|  |                                | $\displaystyle=\sum_{P\in{\mathcal{P}}_{uv}}\prod_{e\in P}\beta w_{e}$ |  | (13) |

Therefore, the Katz index can be viewed as a path formulation with the *summation* operator $+$, the *multiplication* operator $\times$ and the edge representations $\beta w_{e}$. $\Box$

### A.2 Personalized PageRank

The personalized PageRank (PPR) for $u$ computes the stationary distribution over nodes generated by an infinite random walker, where the walker moves to a neighbor node with probability $\alpha$ and returns to the source node $u$ with probability $1-\alpha$ at each step. The probability of a node $v$ from a source node $u$ has the following closed-form solution [[24](https://arxiv.org/html/2106.06935v1#bib.bib24)]

|  | $\text{PPR}(u,v)=(1-\alpha)\sum_{t=1}^{\infty}\alpha^{t}{\bm{e}}_{u}^{\top}({\bm{D}}^{-1}{\bm{A}})^{t}{\bm{e}}_{v}$ |  | (14) |
| --- | ------------------------------ | --- | ---- |

where ${\bm{D}}$ is the degree matrix and ${\bm{D}}^{-1}{\bm{A}}$ is the (random walk) normalized adjacency matrix.
Note that ${\bm{e}}_{u}^{\top}({\bm{D}}^{-1}{\bm{A}})^{t}{\bm{e}}_{v}$ computes the probability of $t$-step random walks from $u$ to $v$.

See [2](https://arxiv.org/html/2106.06935v1#Thmthm2 "Theorem 2 ‣ 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") Proof. We omit the coefficient $1-\alpha$, since it is always positive and has no effect on the ranking of different node pairs.
Then we have

|  | $\displaystyle\text{PPR}(u,v)$ | $\displaystyle\propto\sum_{t=1}^{\infty}\alpha^{t}\sum_{P\in{\mathcal{P}}_{uv}:&#124;P&#124;=t}\prod_{(a,b)\in P}\frac{w_{ab}}{\sum_{b^{\prime}\in{\mathcal{N}}(a)}w_{ab^{\prime}}}$ |  | (15) |
| --- | ------------------------------ | ------------------------------ | --- | ---- |
|  |                                | $\displaystyle=\sum_{P\in{\mathcal{P}}_{uv}}\prod_{(a,b)\in P}\frac{\alpha w_{ab}}{\sum_{b^{\prime}\in{\mathcal{N}}(a)}w_{ab^{\prime}}}$ |  | (16) |

where the *summation* operator is $+$, the *multiplication* operator is $\times$ and edge representations are random walk probabilities scaled by $\alpha$. $\Box$

### A.3 Graph Distance

Graph distance (GD) is defined as the minimum length of all paths between $u$ and $v$.

See [3](https://arxiv.org/html/2106.06935v1#Thmthm3 "Theorem 3 ‣ 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") Proof. Since the length of a path is the sum of edge lengths in the path, we have

|  | $\text{GD}(u,v)=\min_{P\in{\mathcal{P}}_{uv}}\sum_{e\in P}w_{e}$ |  | (17) |
| --- | ------------------------------ | --- | ---- |

Here the *summation* operator is $\min$, the *multiplication* operator is $+$ and the edge representations are the lengths of edges. $\Box$

### A.4 Widest Path

The widest path (WP), also known as the maximum capacity path, is aimed at finding a path between two given nodes, such that the path maximizes the minimum edge weight in the path.

See [4](https://arxiv.org/html/2106.06935v1#Thmthm4 "Theorem 4 ‣ 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") Proof. Given two nodes $u$ and $v$, we can write the widest path as

|  | $\displaystyle\text{WP}(u,v)=\max_{P\in{\mathcal{P}}_{uv}}\min_{e\in P}w_{e}$ |  | (18) |
| --- | ------------------------------ | --- | ---- |

Here the *summation* operator is $\max$, the *multiplication* operator is $\min$ and the edge representations are plain edge weights. $\Box$

### A.5 Most Reliable Path

For a graph with non-negative edge probabilities, the most reliable path (MRP) is the path with maximal probability from a start node to an end node. This is also known as Viterbi algorithm [[55](https://arxiv.org/html/2106.06935v1#bib.bib55)] used in the maximum a posterior (MAP) inference of hidden Markov models (HMM).

See [5](https://arxiv.org/html/2106.06935v1#Thmthm5 "Theorem 5 ‣ 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") Proof. For a start node $u$ and an end node $v$, the probaility of their most reliable path is

|  | $\displaystyle\text{MRP}(u,v)=\max_{P\in{\mathcal{P}}_{uv}}\prod_{e\in P}w_{e}$ |  | (19) |
| --- | ------------------------------ | --- | ---- |

Here the *summation* operator is $\max$, the *multiplication* operator is $\times$ and the edge representations are edge probabilities. $\Box$

## Appendix B Generalized Bellman-Ford Algorithm

First, we prove that the path formulation can be efficiently solved by the generalized Bellman-Ford algorithm when the operators $\langle\oplus,\otimes\rangle$ satisfy a semiring.
Then, we show that traditional methods satisfy the semiring assumption and therefore can be solved by the generalized Bellman-Ford algorithm.

### B.1 Preliminaries on Semirings

Semirings are algebraic structures with two operators, *summation* $\oplus$ and *multiplication* $\otimes$, that share similar properties with the natural summation and the natural multiplication defined on integers. Specifically, $\oplus$ should be commutative, associative and have an identity element $\textcircled{\scriptsize{0}}$. $\otimes$ should be associative and have an identity element $\textcircled{\scriptsize{1}}$. Mathematically, the *summation* $\oplus$ satisfies

- •

  Commutative Property. $a\oplus b=b\oplus a$

- •

  Associative Property. $(a\oplus b)\oplus c=a\oplus(b\oplus c)$

- •

  Identity Element. $a\oplus\textcircled{\scriptsize{0}}=a$

The *multiplication* $\otimes$ satisfies

- •

  Associative Property. $(a\otimes b)\otimes c=a\otimes(b\otimes c)$

- •

  Absorption Property. $a\otimes\textcircled{\scriptsize{0}}=\textcircled{\scriptsize{0}}\otimes a=\textcircled{\scriptsize{0}}$

- •

  Identity Element. $a\otimes\textcircled{\scriptsize{1}}=\textcircled{\scriptsize{1}}\otimes a=a$

Additionally, $\otimes$ should be distributive over $\oplus$.

- •

  Distributive Property (Left). $a\otimes(b\oplus c)=(a\otimes b)\oplus(a\otimes c)$

- •

  Distributive Property (Right). $(b\oplus c)\otimes a=(b\otimes a)\oplus(c\otimes a)$

Note semirings differ from natural arithmetic operators in two aspects. First, the *summation* operator $\oplus$ does not need to be invertible, e.g., min or max. Second, the *multiplication* operator $\otimes$ does not need to be commutative nor invertible, e.g., matrix multiplication.

### B.2 Generalized Bellman-Ford Algorithm for Path Formulation

Now we prove that the generalized Bellman-Ford algorithm computes the path formulation when the operators $\langle\oplus,\otimes\rangle$ satisfy a semiring. It should be stressed that the generalized Bellman-Ford algorithm for path problems has been proved in [[3](https://arxiv.org/html/2106.06935v1#bib.bib3)], and not a contribution of this paper. Here we apply the proof to our proposed path formulation.

The generalized Bellman-Ford algorithm computes the following iterations for all $v\in{\mathcal{V}}$

|  | $\displaystyle{\bm{h}}_{q}^{(t)}(u,v)$ | $\displaystyle\leftarrow\left(\bigoplus_{(x,r,v)\in{\mathcal{E}}(v)}{\bm{h}}_{q}^{(t-1)}(u,x)\otimes{\bm{w}}_{q}(x,r,v)\right)\oplus{\bm{h}}_{q}^{(0)}(u,v)$ |  | ([4](https://arxiv.org/html/2106.06935v1#S3.E4 "In 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction")) |

###### Lemma 1

After $t$ Bellman-Ford iterations, the intermediate representation ${\bm{h}}^{(t)}_{q}(u,v)$ aggregates all path representations within a length of $t$ edges for all $v$. That is

|  | ${\bm{h}}_{q}^{(t)}(u,v)=\bigoplus_{P\in{\mathcal{P}}_{uv}:&#124;P&#124;\leq t}\bigotimes_{i=1}^{&#124;P&#124;}{\bm{w}}_{q}(e_{i})$ |  | (20) |

Proof. For the base case $t=0$, there is a single path of length $0$ from $u$ to itself and no path to other nodes. Due to the product definition of path representations, a path of length $0$ is equal to the *multiplication* identity $\textcircled{\scriptsize{1}}_{q}$. Similarly, a summation of no path is equal to the *summation* identity $\textcircled{\scriptsize{0}}_{q}$. Therefore, we have ${\bm{h}}_{q}^{(0)}(u,v)=\text{1}_{q}(u=v)=\bigoplus_{P\in{\mathcal{P}}_{uv}:&#124;P&#124;=0}\bigotimes_{i=1}^{&#124;P&#124;}{\bm{w}}_{q}(e_{i})$.

|  |                                | $\displaystyle=\left\{\bigoplus_{(x,r,v)\in{\mathcal{E}}(v)}\left[\bigoplus_{P\in{\mathcal{P}}_{ux}:&#124;P&#124;\leq t-1}\left(\bigotimes_{i=1}^{&#124;P&#124;}{\bm{w}}_{q}(e_{i})\right)\otimes{\bm{w}}_{q}(x,r,v)\right]\right\}\oplus{\bm{h}}^{(0)}_{q}(u,v)$ |  | (23) |

|  |                                | $\displaystyle=\bigoplus_{P\in{\mathcal{P}}_{uv}:&#124;P&#124;\leq t}\bigotimes_{i=1}^{&#124;P&#124;}{\bm{w}}_{q}(e_{i}),$ |  | (25) |

where Equation [22](https://arxiv.org/html/2106.06935v1#A2.E22 "In B.2 Generalized Bellman-Ford Algorithm for Path Formulation ‣ Appendix B Generalized Bellman-Ford Algorithm ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") substitutes the inductive assumption for ${\bm{h}}_{q}^{(t-1)}(u,x)$, Equation [23](https://arxiv.org/html/2106.06935v1#A2.E23 "In B.2 Generalized Bellman-Ford Algorithm for Path Formulation ‣ Appendix B Generalized Bellman-Ford Algorithm ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") uses the distributive property of $\otimes$ over $\oplus$. $\Box$

By comparing Lemma [1](https://arxiv.org/html/2106.06935v1#Thmtheorem1 "Lemma 1 ‣ B.2 Generalized Bellman-Ford Algorithm for Path Formulation ‣ Appendix B Generalized Bellman-Ford Algorithm ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") and Equation [10](https://arxiv.org/html/2106.06935v1#A1.E10 "In Appendix A Path Formulations for Traditional Methods ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction"), we can see the intermediate representation converges to our path formulation $\lim_{t\rightarrow\infty}{\bm{h}}_{q}^{(t)}(u,v)={\bm{h}}_{q}(u,v)$. More specifically, at most $&#124;{\mathcal{V}}&#124;$ iterations are required if we only consider simple paths, i.e., paths without repeating nodes. In practice, for link prediction we find it only takes a very small number of iterations (e.g., $T=6$) to converge, since long paths make negligible contribution to the task.

### B.3 Traditional Methods

See [6](https://arxiv.org/html/2106.06935v1#Thmthm6 "Theorem 6 ‣ 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") Proof. Given that the generalized Bellman-Ford algorithm solves the path formulation when $\langle\oplus,\otimes\rangle$ satisfy a semiring, we only need to show that the operators of the path formulations for traditional methods satisfy semiring structures.

Katz index (Theorem [1](https://arxiv.org/html/2106.06935v1#Thmthm1 "Theorem 1 ‣ 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction")) and personalized PageRank (Theorem [2](https://arxiv.org/html/2106.06935v1#Thmthm2 "Theorem 2 ‣ 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction")) use the natural summation $+$ and the natural multiplication $\times$, which obviously satisfy a semiring.

Graph distance (Theorem [3](https://arxiv.org/html/2106.06935v1#Thmthm3 "Theorem 3 ‣ 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction")) uses $\min$ for *summation* and $+$ for *multiplication*. The corresponding identities are $\textcircled{\scriptsize{0}}=+\infty$ and $\textcircled{\scriptsize{1}}=0$. It is obvious that $+$ satisfies the associative property and has identity element $0$.

- •

  Commutative Property. $\min(a,b)=\min(b,a)$

- •

  Associative Property. $\min(\min(a,b),c)=\min(a,\min(b,c))$

- •

  Identity Element. $\min(a,+\infty)=a$

- •

  Absorption Property. $a+\infty=\infty+a=+\infty$

- •

  Distributive Property (Left). $a+\min(b,c)=\min(a+b,a+c)$

- •

  Distributive Property (Right). $\min(b,c)+a=\min(b+a,c+a)$

Widest path (Theorem [4](https://arxiv.org/html/2106.06935v1#Thmthm4 "Theorem 4 ‣ 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction")) uses $\max$ for *summation* and $\min$ for *multiplication*. The corresponding identities are $\textcircled{\scriptsize{0}}=-\infty$ and $\textcircled{\scriptsize{1}}=+\infty$. We have

- •

  Commutative Property. $\max(a,b)=\max(b,a)$

- •

  Associative Property. $\max(\max(a,b),c)=\max(a,\max(b,c))$

- •

  Identity Element. $\max(a,-\infty)=a$

- •

  Associative Property. $\min(\min(a,b),c)=\min(a,\min(b,c))$

- •

  Absorption Property. $\min(a,-\infty)=\min(-\infty,a)=-\infty$

- •

  Identity Element. $\min(a,+\infty)=\min(+\infty,a)=a$

- •

  Distributive Property (Left). $\min(a,\max(b,c))=\max(\min(a,b),\min(a,c))$

- •

  Distributive Property (Right). $\min(\max(b,c),a)=\max(\min(b,a),\min(c,a))$

where the distributive property can be proved by enumerating all possible orders of $a$, $b$ and $c$.

Most reliable path (Theorem [5](https://arxiv.org/html/2106.06935v1#Thmthm5 "Theorem 5 ‣ 3.1 Path Formulation for Link Prediction ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction")) uses $\max$ for *summation* and $\times$ for *multiplication*. The corresponding identities are $\textcircled{\scriptsize{0}}=0$ and $\textcircled{\scriptsize{1}}=1$, since all path representations are probabilities in $[0,1]$. It is obvious that $\times$ satisfies the associative property, the absorption property and has identity element $0$.

- •

  Commutative Property. $\max(a,b)=\max(b,a)$

- •

  Associative Property. $\max(\max(a,b),c)=\max(a,\max(b,c))$

- •

  Identity Element. $\max(a,0)=a$

- •

  Distributive Property (Left). $a\times\max(b,c)=\max(a\times b,a\times c)$

- •

  Distributive Property (Right). $\max(b,c)\times a=\max(b\times a,c\times a)$

where the identity element and the distributive property hold for non-negative elements. $\Box$

### C.1 NBFNet

###### Lemma 2

The time complexity of one NBFNet run (Algorithm [1](https://arxiv.org/html/2106.06935v1#alg1 "Algorithm 1 ‣ 3.2 Neural Bellman-Ford Networks ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction")) is $O(T(&#124;{\mathcal{E}}&#124;d+&#124;{\mathcal{V}}&#124;d^{2}))$.

Proof. We break the time complexity by Indicator, Message and Aggregate functions.

Indicator is called $&#124;{\mathcal{V}}&#124;$ times, and a single call to Indicator takes $O(d)$ time. Message is called $T(&#124;{\mathcal{E}}&#124;+&#124;{\mathcal{V}}&#124;)$ times, and a single call to Message, i.e., a relation operator, takes $O(d)$ time. Aggregate is called $T&#124;{\mathcal{V}}&#124;$ times over a total of $T&#124;{\mathcal{E}}&#124;$ messages with $d$ dimensions. Each call to Aggregate additionally takes $O(d^{2})$ time due to the linear transformations in the function.

Therefore, the total complexity is summed to $O(T(&#124;{\mathcal{E}}&#124;d+&#124;{\mathcal{V}}&#124;d^{2}))$. $\Box$

In practice, we find a small constant $T$ works well for link prediction, and Lemma [2](https://arxiv.org/html/2106.06935v1#Thmtheorem2 "Lemma 2 ‣ C.1 NBFNet ‣ Appendix C Comparison of GNN Frameworks ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") can be reduced to $O(&#124;{\mathcal{E}}&#124;d+&#124;{\mathcal{V}}&#124;d^{2})$ time.

Now consider applying NBFNet to infer the likelihood of all possible triplets. Without loss of generality, assume we want to predict the tail entity for each head entity and relation $p(v&#124;u,q)$. We group triplets with the same condition $u,q$ together, where each group contains $&#124;{\mathcal{V}}&#124;$ triplets. For triplets in a group, we only need to execute Algorithm [1](https://arxiv.org/html/2106.06935v1#alg1 "Algorithm 1 ‣ 3.2 Neural Bellman-Ford Networks ‣ 3 Methodology ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") once to get their predictions. Therefore, the amortized time for a single triplet is $O\left(\frac{&#124;{\mathcal{E}}&#124;d}{&#124;{\mathcal{V}}&#124;}+d^{2}\right)$.

### C.2 RGCN

RGCN is a message-passing GNN applied to multi-relational graphs, with the message function being a per-relation linear transformation. The time complexity of RGCN is similar to Lemma [2](https://arxiv.org/html/2106.06935v1#Thmtheorem2 "Lemma 2 ‣ C.1 NBFNet ‣ Appendix C Comparison of GNN Frameworks ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction"), except that each call to the message function takes $O(d^{2})$ time due to the linear transformation. Therefore, the total complexity is $O(T(&#124;{\mathcal{E}}&#124;d^{2}+&#124;{\mathcal{V}}&#124;d^{2}))$, where $T$ refers to the number of layers in RGCN. Since $&#124;{\mathcal{V}}&#124;\leq&#124;{\mathcal{E}}&#124;$, the complexity is reduced to $O(T&#124;{\mathcal{E}}&#124;d^{2})$77 7 By moving the linear transformations from the message function to the aggregation function, one can also get an implementation of RGCN with $O(T&#124;{\mathcal{V}}&#124;&#124;{\mathcal{R}}&#124;d^{2})$ time, which is better for dense graphs but worse for sparse graphs. For the datasets used in this paper, the above $O(T&#124;{\mathcal{E}}&#124;d^{2})$ implementation is better.. In practice, $T$ is a small constant and we get $O(&#124;{\mathcal{E}}&#124;d^{2})$ complexity.

While directly executing RGCN once for each triplet is costly, a smart way to apply RGCN for inference is to first compute all node representations, and then perform link prediction with the node representations. The first step runs RGCN once for $&#124;{\mathcal{V}}&#124;^{2}&#124;{\mathcal{R}}&#124;$ triplets, while the second step takes $O(d)$ time. Therefore, the amortized time for a single triplet is $O\left(\frac{&#124;{\mathcal{E}}&#124;d^{2}}{&#124;{\mathcal{V}}&#124;^{2}&#124;{\mathcal{R}}&#124;}+d\right)$. For large graphs and reasonable choices of $d$, we have $&#124;{\mathcal{E}}&#124;d\leq&#124;{\mathcal{V}}&#124;^{2}&#124;{\mathcal{R}}&#124;$ and the amortized time can be reduced to $O(d)$.

### C.3 GraIL

GraIL first extracts a local subgraph surrounding the link, and then applies RGCN to the local subgraph. Therefore, its amortized time is the same as that of one RGCN run, which is $O(&#124;{\mathcal{E}}&#124;d^{2})$.

Note that one may still run GraIL on large graphs by restricting the local subgraphs to be very small, e.g., within 1-hop neighborhood of the query entities. However, this will severely harm the performance of link prediction. Moreover, most real-world graphs are small-world networks, and a moderate radius can easily cover a non-trivial number of nodes and edges, which costs a lot of time for GraIL.

### C.4 NeuralLP / DRUM

DRUM can be viewed as a special case of NBFNet with Message being Hadamard product and Aggregate being natural summation. NeuralLP is a special case of DRUM where the dimension $d$ equals to 1. Since there is no linear transformation in their Aggregate functions, the amortized time complexity for the message passing part is $O\left(\frac{T&#124;{\mathcal{E}}&#124;d}{&#124;{\mathcal{V}}&#124;}\right)$. Both DRUM and NeuralLP additionally use an LSTM to learn the edge weights for each layer, which additionally costs $O(Td^{2})$ time for $T$ layers. $T$ is small and can be ignored like in other methods. Therefore, the amortized time of two parts is summed to $O\left(\frac{&#124;{\mathcal{E}}&#124;d}{&#124;{\mathcal{V}}&#124;}+d^{2}\right)$.

## Appendix F Implementation Details

Our implementation generally follows the open source codebases of knowledge graph completion88 8 <https://github.com/DeepGraphLearning/KnowledgeGraphEmbedding>. MIT license. and homogeneous graph link prediction99 9 <https://github.com/tkipf/gae>. MIT license.. Table [12](https://arxiv.org/html/2106.06935v1#A6.T12 "Table 12 ‣ Appendix F Implementation Details ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") lists the hyperparameter configurations for different datasets. Table [13](https://arxiv.org/html/2106.06935v1#A6.T13 "Table 13 ‣ Appendix F Implementation Details ‣ Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction") shows the wall time of training and inference on different datasets.

Data Augmentation. For knowledge graphs, we follow previous works [[63](https://arxiv.org/html/2106.06935v1#bib.bib63), [41](https://arxiv.org/html/2106.06935v1#bib.bib41)] and augment each triplet $\langle$u, q, v$\rangle$ with a flipped triplet $\langle$v, q-1, u$\rangle$. For homogeneous graphs, we follow previous works [[27](https://arxiv.org/html/2106.06935v1#bib.bib27), [28](https://arxiv.org/html/2106.06935v1#bib.bib28)] and augment each node $u$ with a self loop $\langle$u, u$\rangle$.

Architecture Details. We apply Layer Normalization [[1](https://arxiv.org/html/2106.06935v1#bib.bib1)] and short cut connection to accelerate the training of NBFNet. Layer Normalization is applied after each Aggregate function. The feed-forward network $f(\cdot)$ is instantiated as a MLP. ReLU is used as the activation function for all hidden layers. For knowledge graphs, we use two separate NBFNet instances to model the conditional likelihood of tails $p(v&#124;u,q)$ and heads $p(u&#124;v,q^{-1})$ respectively. For homogeneous graphs, due to their undirected nature, we share the parameters of two NBFNet instances, and symmetrize the pair representation by taking the sum of ${\bm{h}}(u,v)$ and ${\bm{h}}(v,u)$.

Training Details. We train NBFNet on 4 Tesla V100 GPUs with standard data parallelism. During training, we drop out edges that directly connect query node pairs to encourage the model to capture longer paths and prevent overfitting. We apply early stopping according to the mean reciprocal rank (MRR) on the validation set.
